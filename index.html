사용법

처음 한 번만

  1. 공장 버튼(성남·원주·대구)을 누릅니다.
  2. 관리자·당직자·PC 담당자를 넣습니다. 이름 뒤에 직함을 붙이면 보고서에 그대로 나와요 (예: 홍길동 센터장).
  3. '목록에서 선택'에 자주 쓰는 사람을 저장해 두면 다음부터 누르기만 하면 돼요.
  4. 보고서를 한 번 만들고 나면, 다음부터는 공장 버튼만 눌러도 세 사람이 자동으로 채워져요.

보고서 쓰기

  1. 점검일: 토·일 버튼으로 바로 고를 수 있어요.
  2. 점검구분: 작업 전 / 작업 중 / 작업 후.
  3. 작업마다: 공사명 → 업체(목록) → 인원·연락처 → 공사내용.
  4. 작업구분·주요 안전조치를 누릅니다. 작업구분을 고르면 그 작업에서 확인할 것이 목록으로 나와요 (보고서에는 안 들어가요).
  5. 사진: 작업당 4장까지. 2장까지는 한 칸, 3~4장이면 '[1] 공사명-1', '[1] 공사명-2' 두 칸으로 나란히 들어가요. 특이사항은 두 칸 아래에 같은 내용으로 들어가요.
  6. 점검 내용 / 특이사항: 항목마다 ①, ②, ③으로 나뉘어 들어가요. 엔터를 누르면 다음 항목이 생기고, 보고서에서 노란 칸으로 강조돼요.

'확인 필요'가 뜨면

  • 사진이 없는 작업이 있으면 아래쪽 막대와 작업 카드에 알려 줘요.
  • 경고가 있어도 보고서는 만들어져요.

보고서 만들고 보내기

  1. '보고서 이미지 만들기'를 누르면 미리보기가 나와요. 남은 확인 사항도 함께 보여 줘요.
  2. 공유하기: 문자·메일·사내 메신저 등 폰에 있는 앱으로 바로 보내요.
  3. 이미지 저장 / PPT 받기 / PDF 받기: 파일로 저장해 첨부해요. PPT는 표와 글자를 고칠 수 있어요.
  4. 만든 보고서는 보관함에 자동 저장돼요.

작업 전 → 중 → 후 이어 쓰기

  • '새로 작성' → 같은 작업으로 다음 점검 쓰기: 작업 목록은 그대로 두고 사진·특이사항·측정값만 비워요. 점검구분은 다음 단계로 바뀌어요.
  • 다른 공사를 처음부터 쓸 땐 작업 모두 비우기.

보관함

  • 이 폰: 내가 만든 보고서. 이미지·PPT·PDF 다시 받기, 불러와서 고치기, 삭제.
  • 팀 전체: 주말 제출 현황(공장별 작업 전·후)과 공장별 보고 목록.

팀 드라이브 연결

  • 관리자에게 받은 연결 링크(문자·메일)를 폰에서 열면 바로 연결돼요.
  • 직접 연결: 보관함 → 팀 드라이브 연결 → 웹 앱 주소와 팀 코드 입력.
  • 연결되면 보고서를 만들 때마다 이미지·PDF·PPT가 드라이브 공장별 폴더에 올라가요.

사진 찍을 때

  • 작업마다 최소 1장. 작업 후 점검은 완료 상태로.
  • 밀폐: 측정 화면, 감시인, 안전대 착용.
  • 화기: 소화기·방화포가 보이게.
  • 바닥 개구부: 덮개·펜스·표지.
  • 전기·설비: 잠금장치(LOTOTO)를 건 모습.
